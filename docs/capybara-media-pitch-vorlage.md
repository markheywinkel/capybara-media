# Pitch-Vorlage — Capybara Media

Skalen: Boulevard-Grad und Aufwand jeweils 1-5.
Boulevard-Grad: 1 = investigativ/seriös, 5 = reißerisch/Boulevard — bleibt im Spiel **verdeckt**, nur an der Headline erkennbar.
Aufwand: benötigtes Skill-Level der zuständigen Rolle — bleibt im Spiel **sichtbar**.
